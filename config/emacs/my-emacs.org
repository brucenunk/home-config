#+title: Emacs configuration
#+property: header-args:emacs-lisp :tangle no :mkdirp yes :comments no :results silent

This is the authoring entry point for our Emacs configuration, inspired by [[https://protesilaos.com/emacs/dotemacs][Prot's literate configuration]]. It records what is enabled and why. The implementation lives in [[file:my-lisp/][my-lisp/]]; tests live in [[file:tests/][tests/]].

Nix tangles this document during the build and deploys ordinary Lisp. Emacs never parses this document at startup. Do not edit the generated files. Use =scripts/tangle-emacs-config OUTPUT-DIRECTORY= for a disposable local render; see [[file:../../docs/emacs-literate.md][the maintenance guide]] for verification and deployment boundaries.

Nix owns package and tree-sitter grammar installation. =use-package= only configures those packages. Each package has one owning declaration. Hooks, key bindings, settings and integration calls stay here; function bodies stay in handwritten libraries. The prose describes the current behaviour and trade-offs without assuming undocumented historical reasons.

* Early startup
:PROPERTIES:
:header-args:emacs-lisp+: :tangle early-init.el
:END:

Avoid startup chrome and keep package provisioning in Nix. Package activation remains enabled so Nix-provided autoloads are available. The Custom file is a local override, not a second repository-maintained configuration source.

Disable backup copies and lockfiles, keeping those extra files out of working directories. This gives up Emacs’s backup-copy recovery and file-lock coordination between editing processes; it does not disable auto-save. Silence native-compilation warning reports to reduce noise, at the cost of making compilation problems less visible. These are existing policies, not recommendations imported from the reference configuration.

#+begin_src emacs-lisp
;; -*- lexical-binding: t -*-
;; Generated from my-emacs.org; do not edit.

(setq-default backup-inhibited t
	      create-lockfiles nil
              custom-file (expand-file-name "custom.el" user-emacs-directory)
	      inhibit-startup-message t
	      make-backup-files nil
	      native-comp-async-report-warnings-errors 'silent
	      use-short-answers t)

;; Keep package.el startup activation for Nix-provided package autoloads, but
;; leave package provisioning exclusively to Nix.
(setq package-archives nil)

(menu-bar-mode -1)
(scroll-bar-mode -1)
(tool-bar-mode -1)

(when (featurep 'ns)
  (setq ns-use-thin-smoothing t)
  (add-to-list 'default-frame-alist '(ns-transparent-titlebar . t)))

(setq frame-resize-pixelwise t)
#+end_src

** Font presets

Upstream: [[https://github.com/protesilaos/fontaine][package homepage]].

Use Aporetic Serif Mono for code and Bricolage Grotesque for prose. =my/fontaine-setup-frame= restores a known preset after startup and when a frame is created, leaving terminal frames alone. Register =after-make-frame-functions= explicitly because it is an abnormal hook that receives the new frame, not a conventional =-hook= variable.

#+begin_src emacs-lisp
(use-package fontaine
  :ensure nil
  :hook (after-init . my/fontaine-setup-frame)
  :bind ("C-c F" . fontaine-set-preset)
  :init
  ;; This abnormal hook takes a frame and has no conventional -hook suffix.
  (add-hook 'after-make-frame-functions #'my/fontaine-setup-frame)
  :custom
  (fontaine-presets
        '((t
           :default-family "Aporetic Serif Mono"
           :default-height 130
           :fixed-pitch-family "Aporetic Serif Mono"
           :fixed-pitch-height 1.0
           :variable-pitch-family "Bricolage Grotesque"
           :variable-pitch-height 1.0)
          (aporetic-serif-mono)
          (aporetic-sans-mono
           :default-family "Aporetic Sans Mono"
           :fixed-pitch-family "Aporetic Sans Mono")
          (open-sans
           :variable-pitch-family "Open Sans"))))
#+end_src

** Prose with fixed-width code

Org, Markdown and agent viewports use mixed-pitch text. Keep these shared mode hooks in the single =mixed-pitch= declaration: the package being enabled owns the registration, even when several features use it. Keep code and tables fixed-width, including renderer-specific faces.

=my/viewport-prompt-variable-pitch= lets echoed viewport prompts use the prose font without changing documentation faces. =my/refresh-mixed-pitch-mode= reapplies active remaps after Fontaine changes fonts. Keep all six registrations together in =:hook=. Bare mode names enable =mixed-pitch-mode= by convention; explicit pairs name our custom callbacks. The font-refresh helper ignores buffers where mixed-pitch is not active, including before the package loads. Agent-specific header styling is configured in [[*Pi and the viewport interface][Agents]].

#+begin_src emacs-lisp
(use-package mixed-pitch
  :ensure nil
  :hook (markdown-mode
         org-mode
         agent-shell-viewport-view-mode
         agent-shell-viewport-edit-mode
         (mixed-pitch-mode . my/viewport-prompt-variable-pitch)
         (fontaine-set-preset . my/refresh-mixed-pitch-mode))
  :config
  ;; mixed-pitch already keeps Org blocks, code/verbatim, tables, metadata,
  ;; checkboxes, and indentation fixed-pitch; retain its native face list.
  ;; The renderer's base faces also cover source labels, syntax-highlighted
  ;; bodies, and table headers/borders through inheritance.  Remap them only
  ;; in mixed-pitch buffers; ordinary shell buffers keep their own font.
  ;; The composer reuses Org or Markdown faces, keeping all markup editable.
  ;; Include pre-face for untyped/unknown-language code bodies too.
  (dolist (face '(markdown-table-face
                  markdown-pre-face
                  agent-shell-markdown-inline-code
                  agent-shell-markdown-source-block
                  agent-shell-markdown-table))
    (add-to-list 'mixed-pitch-fixed-pitch-faces face)))
#+end_src

** Explicit file and word completion

Upstream: [[https://github.com/minad/cape][package homepage]].

Automatic file completion only handles explicit paths, leaving prose, URLs, mentions and slash commands alone. =C-c p f= offers manual file completion; a prefix argument chooses a temporary base directory. Dabbrev starts at three characters and follows file completion in the fallback chain. Use =:bind-keymap= for the global prefix and =:bind= for the command within Cape’s existing map. The explicit CAPF hooks retain depths 80 and 90 so file completion runs before Dabbrev.

#+begin_src emacs-lisp
(use-package cape
  :ensure nil
  :demand t
  :bind-keymap ("C-c p" . cape-prefix-map)
  :bind (:map cape-prefix-map
              ("f" . my/cape-file))
  :config
  (add-hook 'completion-at-point-functions #'my/cape-explicit-file-capf 80)
  (add-hook 'completion-at-point-functions #'my/cape-dabbrev-capf 90))
#+end_src

** Dired

Hide details by default, refresh directory listings, and use another Dired window as the likely copy/move target.

Allow recursive directory copies and deletions without a separate recursion prompt. Prefer moving deleted files to the trash where supported, but do not treat trash as a guaranteed recovery mechanism. #+begin_src emacs-lisp

  :hook ((dired-mode . dired-hide-details-mode)
         (dired-mode . auto-revert-mode))
  :custom
  (delete-by-moving-to-trash t)
  (dired-dwim-target t)
  (dired-recursive-copies 'always)
  (dired-recursive-deletes 'always))

** Notes and task capture

New notes use Org under =~/work/docs/=; task capture remains scoped to its =tasks/= subtree. Show notes on empty startup without replacing explicitly requested buffers. Defer new-note refresh and renaming until the file exists. Task-specific debounce and redisplay advice is installed through the helper registration call below, without forcing autorevert to load. Its library option =my/denote-task-auto-revert-debounce-interval= defaults to 0.3 seconds.

The Dired hook identifies notes in the configured collection, and the Markdown hook highlights Denote links in existing Markdown notes. =my/denote-startup= opens the notes view only on an otherwise empty startup. =my/denote-rename-new-buffer-maybe= defers buffer naming until a new note exists, replacing Denote’s immediate rename hooks. =my/denote-task-auto-revert-enable-maybe= enables refresh only for task files.

The link advice =my/denote-link-normalize-file-arg= normalizes file arguments before inserting links. The collection-specific revert rule permits unattended refresh of unmodified notes. =my/denote-register-auto-revert= installs the task debounce and redisplay integration regardless of whether autorevert loads before or after Denote, without loading it eagerly. Settings belong in =:custom=; enabling modes, removing upstream hooks, adding advice and registering that integration belong in =:config=.

#+begin_src emacs-lisp
(use-package denote
  :ensure nil
  :demand t
  :hook ((emacs-startup . my/denote-startup)
         (dired-mode . denote-dired-mode-in-directories)
         (markdown-mode . denote-fontify-links-mode-maybe)
         (denote-after-new-note . my/denote-rename-new-buffer-maybe)
         (find-file . my/denote-rename-new-buffer-maybe)
         (find-file . my/denote-task-auto-revert-enable-maybe))
  :bind (("C-c n T" . my/denote-task)
         ("C-c n n" . denote)
         ("C-c n t" . denote-template)
         ("C-c n r" . denote-rename-file)
         ("C-c n l" . denote-link)
         ("C-c n b" . denote-backlinks))
  :custom
  (denote-directory (expand-file-name "~/work/docs/"))
  (denote-dired-directories (list denote-directory))
  (denote-dired-directories-include-subdirectories t)
  (denote-known-keywords nil)
  (denote-file-type 'org)
  (denote-rename-confirmations nil)
  (denote-templates
   '((task-workflow . (lambda () (my/denote-template "task-workflow.org")))))
  :config
  (require 'my-denote-task)
  (advice-add #'denote-link :around #'my/denote-link-normalize-file-arg)
  (add-to-list 'revert-without-query
               (concat "^" (regexp-quote (file-name-as-directory denote-directory))))
  (denote-rename-buffer-mode 1)
  (remove-hook 'denote-after-new-note-hook
               #'denote-rename-buffer-rename-function-or-fallback)
  (remove-hook 'find-file-hook #'denote-rename-buffer-rename-function-or-fallback)
  ;; Genuine Denote/autorevert integration; support either package load order.
  (my/denote-register-auto-revert))
#+end_src

      (jsonnet-mode . "jsonnet-language-server")
